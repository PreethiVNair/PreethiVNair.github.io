# Lab 2: Spam Classification and Outlier Detection

## Overview

This lab explores how probability and statistical techniques can be applied to real-world datasets.

## Part A: Email Spam Classification

- Trained Gaussian Naive Bayes and Multinomial Naive Bayes models.
- Compared their performance using accuracy, precision, recall, and F1-score.
- Selected the better-performing model based on F1-score.

## Part B: Airbnb Price Outlier Detection

- Explored Airbnb prices using statistical measures and visualizations.
- Compared IQR, standard deviation, and percentile methods for detecting outliers.
- Created and exported a cleaned Airbnb dataset.

## Tools and Libraries

Python, Pandas, NumPy, Matplotlib, and Scikit-learn.

## Results

- Multinomial Naive Bayes performed better for spam classification.
- The IQR method was selected for cleaning the Airbnb dataset.
